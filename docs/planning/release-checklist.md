# Release readiness checklist

- [ ] Required AAVLD approval is recorded according to the governance policy.
- [ ] Each substantive statement is traceable to an authoritative source or labeled as guidance/example.
- [ ] All substantive review comments have a disposition.
- [ ] Version, release date, and changelog are complete.
- [ ] Final Word/PDF/web artifacts, if used, match the canonical approved source.
- [ ] Accessibility and rendering checks are complete for published artifacts.
- [ ] Source material, decision records, review artifacts, and release assets are archived.
- [ ] Deferred work is tracked for a future release.
