# Committee review package checklist

- [ ] Tagged Committee Review Draft and rendered release candidate.
- [ ] Changelog of substantive changes since the last stable artifact.
- [ ] Requirements traceability matrix with unresolved rows highlighted.
- [ ] Source register and source-classification decisions.
- [ ] Open issue list grouped into editorial, substantive, and decision-needed items.
- [ ] Decision agenda with proposed options, rationale, and owner.
- [ ] Review instructions, comment deadline, and disposition method.

The committee reviews and approves content; this checklist does not itself establish approval authority.
